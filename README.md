# Deer in a Box brand kit

Hi! This is where I keep the artwork for Deer in a Box. If you're looking for a profile picture, a banner, or just the deer head, here's where to find it.

## What to use

| File | Use it for |
| --- | --- |
| [pfp/pfp-full.png](pfp/pfp-full.png) | The full profile picture for socials. |
| [pfp/pfp-no-bg.png](pfp/pfp-no-bg.png) | The deer and box on a transparent background. Use this when you already have a background. |
| [pfp/pfp-trimmed.png](pfp/pfp-trimmed.png) | The tight crop of the deer head used as the website favicon. |
| [pfp/head.png](pfp/head.png) | The separate deer head for layouts and animation. |
| [banner/banner-full.png](banner/banner-full.png) | The finished banner. |
| [banner/banner-pmc.png](banner/banner-pmc.png) and [banner/banner-reddit.png](banner/banner-reddit.png) | Banners cropped for Planet Minecraft and Reddit. |
| [banner/background-banner.png](banner/background-banner.png) and [banner/text.png](banner/text.png) | The banner background and lettering as separate layers. |
| [generator/index.html](generator/index.html) | Make your own text in the banner style and export it as a PNG. Open it in your browser. |

For a peek animation, stack the back of the box, the head, and the front of the box in that order. Move the head on its own. If you move the box, move both box layers together.

## Colors

| Color | Hex | Where I use it |
| --- | --- | --- |
| Forest | `#0C1711` | Dark backgrounds |
| Deep green | `#14271B` | Panels and cards |
| Moss | `#65A34E` | Borders and accents |
| Lime | `#A4CF6A` | Buttons and links |
| Cream | `#F5EDDA` | Text on dark backgrounds |
| Amber | `#EEB95C` | Highlights |
| Muted green | `#9BAB9D` | Secondary text |

The banner lettering uses a `#F3FC07` to `#9DCB03` gradient with a `#024014` outline. I use Minecraft Ten for big titles and a plain sans serif for body text.

## Using the artwork

Keep the original proportions and leave a little room around the deer and box. If you're resizing the pixel art, use nearest neighbor to keep the edges crisp.

If you're using the artwork to link to or credit the project, use **Deer in a Box** and point to [deerinabox.net](https://deerinabox.net). For other uses, ask me at [TheDeerInABox@gmail.com](mailto:TheDeerInABox@gmail.com).
